## 🚀 **Usage Examples**

### **Basic Usage**
```bash
# Start interactive CLI
nml

# Configure and run simulation
nml config set neurons 500
nml brain initialize
nml brain step 1000
nlm brain save results.nml
```

### **Advanced Scripting**
```bash
# Create simulation script
script.nml:
    nlm config set neurons 1000
    nlm brain initialize
    nlm brain step 5000
    nlm brain save advanced_simulation.nml

# Execute script
nlm --script script.nml
```

### **Configuration Management**
```bash
# Set advanced configuration
nlm config set --neurons 1000 --plasticity 0.8
nlm config validate
nlm config save advanced_config.nml
```
