## USAGE EXAMPLES

### Basic Usage
```bash
# Run basic neural computation
./nlm --mode basic --steps 10000

# Run comprehensive learning experiment
./nlm --mode plasticity --steps 50000 --enable-structural --enable-neuromodulation

# Run memory integration test
./nlm --mode memory --steps 20000 --enable-plasticity

# Export brain state for analysis
./nlm --mode basic --steps 20000 --export-neurons neurons.bin --export-synapses synapses.bin
```

### Advanced Configuration
```bash
# Custom configuration file
./nlm --config myconfig.cfg --mode cognition --steps 30000 --verbose

# Research with full systems
./nlm --enable-development --checkpoint dev_checkpoint.bin --load-state initial_state.bin --benchmark
```

### Python Research Interface
```python
import pynlm

# Create advanced neural configuration
config = pynlm.createDefaultConfig()
config.neuron_count = 1000
config.enable_structural_plasticity = True

# Initialize brain with enhanced memory
brain = pynlm.createBrain(config)

# Process cognitive patterns
pattern = [0.1, 0.5, 0.8, 0.3, 0.9]
concept_id = brain.processCognition(pattern, [0.2, 0.6, 0.4], 0.7, time_step)

# Export research data
brain.saveState("research_data.bin")
```
