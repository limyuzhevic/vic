## CLI Tools

### 1. nlm-train
**Description**: Train brain behaviors with configurable training parameters

**Key Features**:
- Subcommands: `train`, `evaluate`, `import`
- Training modes: Supervised, reinforcement, self-supervised, curriculum
- Support for multiple optimizers (Adam, SGD, RMSprop)
- Learning rate scheduling
- Early stopping
- Model checkpointing and saving
- Progress reporting
- Result export in JSON, CSV, HDF5 formats
- Comprehensive logging and error handling

**Usage Examples**:
```bash
# Show help information
nlm-train --help

# Train with default configuration
nlm-train train --epochs 100 --learning-rate 0.001

# Train with custom configuration file
nlm-train train --config train_config.json

# Evaluate trained model
evalute --model-path ./model.h5 --test-data ./test_data.json

# Import brain from external format
import --source external_model.json --format h5
```

### 2. nlm-simulate
**Description**: Run simulations with customizable settings

**Key Features**:
- Subcommands: `run`, `analyze`, `export`
- Multiple world types: Grid, continuous, graph
- Performance monitoring and tracking
- Real-time visualization support
- Result analysis and statistical testing
- Export in multiple formats
- Comprehensive error handling

**Usage Examples**:
```bash
# Run simulation with default settings
nlm-simulate run --max-steps 1000 --timestep 0.01

# Analyze simulation results
nlm-simulate analyze --results-path ./simulation_results.json --metrics accuracy,loss,f1_score

# Export simulation data
nlm-simulate export --source ./simulation_data.h5 --format json --output-dir ./exports
```

### 3. nlm-visualize
**Description**: Visualize brain state with different visualization options

**Key Features**:
- Subcommands: `create`, `animate`, `compare`, `export`
- Multiple visualization types: Network, connections, activity, heatmap, timeline, dashboard
- Real-time plotting capabilities
- Comparison between multiple brains
- Results dashboard creation
- Activity monitoring
- Export in various formats (PNG, SVG, HTML, PDF, JSON)
- Progress reporting

**Usage Examples**:
```bash
# Create network visualization
nlm-visualize create --brain-file ./brain_data.json --visualization-type network

# Create animation
echate animate --brain-file ./brain_data.json --output-file ./animation.gif --frames 50

# Compare visualizations
nlm-visualize compare --brain-files ./brain1.json ./brain2.json --metric firing_rate

# Export visualization data
nlm-visualize export --brain-file ./brain_data.json --data-format csv --output-file ./data.csv
```

### 4. nlm-export
**Description**: Export experiment results in various formats

**Key Features**:
- Subcommands: `export`, `merge`, `convert`, `validate`
- Support for JSON, CSV, HDF5, and pickle formats
- Batch export operations
- File compression
- Data validation
- Merge multiple experiment results
- Format conversion
- Progress tracking
- Comprehensive error handling

**Usage Examples**:
```bash
# Export experiment results
nlm-export export --source ./experiment_data --formats json,csv,h5 --output-dir ./exports

# Merge multiple experiment results
nlm-export merge --sources ./exp1.json ./exp2.json ./exp3.json --output-file ./merged.json

# Convert experiment data between formats
nlm-export convert --source-file ./data.json --target-format h5 --output-file ./data.h5

# Validate export configuration
nlm-export validate --source ./experiment_data --format json
```

## Shared CLI Utilities

All CLI tools and automation scripts share the following utilities:

### Core Classes:
- **NLMCLI**: Base class for CLI tools with common functionality
- **ProgressReporter**: Progress tracking for long-running operations
- **OutputFormat**: Enumeration of output formats (console, JSON, CSV, table)

### Utility Functions:
- **load_config**: Load JSON configuration files
- **save_config**: Save configuration to JSON files
- **setup_logging**: Configure logging with appropriate formatting
- **format_output**: Format data according to specified format
- **validate_args**: Validate parsed arguments

### Configuration Examples:
- **DEFAULT_TRAIN_CONFIG**: Default training configuration
- **DEFAULT_SIMULATION_CONFIG**: Default simulation configuration
- **DEFAULT_ANALYSIS_CONFIG**: Default analysis configuration

## Configuration File Support

All tools support JSON configuration files with the following structure:

### Basic Configuration Structure:
```json
{
  "tool": {
    "name": "tool_name",
    "version": "1.0.0",
    "description": "Tool description"
  },
  "logging": {
    "level": "INFO",
    "format": "%(asctime)s - %(name)s - %(levelname)s - %(message)s"
  },
  "configuration": {
    "key1": "value1",
    "key2": 123,
    "key3": ["option1", "option2"]
  }
}
```

### Tool-Specific Configurations:
- **Training Configuration**: Epochs, learning rate, batch size, model parameters
- **Simulation Configuration**: Timestep, max steps, world type, agent settings
- **Analysis Configuration**: Metrics, statistical tests, visualization options
- **World Configuration**: World type, size, terrain, agents

- **Data serialization**: Use SerializationManager for result persistence
- **Visualization**: Use VisualizationTools for comprehensive visualization

### Example Integration:
