# NLM Tutorial Documentation

## Overview

This tutorial documentation provides step-by-step guides for using the NLM system at different development phases. Each tutorial builds on the concepts and capabilities of previous phases, leading to a complete understanding of the integrated brain system.

## Table of Contents

1. [Phase 2 Tutorial: LIF Neurons, Spikes, Plasticity](TUTORIALS/PHASE2/README.md)
2. [Phase 3 Tutorial: World Interaction, Reward Learning](TUTORIALS/PHASE3/README.md)
3. [Phase 4 Tutorial: Cognitive Abilities, Prediction](TUTORIALS/PHASE4/README.md)
4. [Phase 6 Tutorial: Complete Integrated Brain](TUTORIALS/PHASE6/README.md)

## Tutorial Structure

Each tutorial follows the same structure:

1. **Learning Objectives** - What you'll accomplish
2. **Prerequisites** - What you need to know
3. **Setup** - Environment and code setup
4. **Concepts** - Underlying theory and principles
5. **Implementation** - Step-by-step code examples
6. **Analysis** - What the results mean
7. **Extensions** - Further exploration possibilities

---

This documentation set is designed to be progressive, starting with the fundamental neural components in Phase 2 and building up to the complete integrated brain in Phase 6.
