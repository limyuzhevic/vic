# Neuron Guide ## Overview Neurons are the fundamental computational units in NLM, implementing Leaky Integrate-and-Fire (LIF) dynamics. Each neuron processes inputs, accumulates membrane potential, and generates spikes when threshold is reached, propagating signals through the neural network. ## LIF Neuron Model ### Core Dynamics NLM implements a simplified Leaky Integrate-and-Fire model, which captures the essential properties of biological neurons while remaining computationally efficient: ``` tau * dV/dt = -g_L * (V - E_L) + I_total ``` Where: - `V` is the membrane potential - `tau` is the membrane time constant - `g_L` is the leak conductance - `E_L` is the resting potential - `I_total` is the total synaptic current ### State Variables #### Membrane Potential (`MembranePotential`) The electrical potential across the neuron membrane that integrates incoming synaptic currents. **Properties**: - `membranePotential`: Current membrane potential (mV) - `restingPotential`: Equilibrium potential (typically -65mV) - `threshold`: Firing threshold (typically -50mV) - `leakConductance`: Membrane conductance for passive current **Dynamics**: - **Integration**: Summation of incoming synaptic currents - **Leak**: Exponential decay toward resting potential - **Reset**: Sudden reset after spike generation #### Firing State (`FiringState`) Represents the current physiological state of the neuron. **States**: - `Resting`: Below threshold, not firing - `Active`: Above threshold, firing spikes - `Refractory`: Recovery period after firing - `Adapting`: Modified dynamics due to adaptation #### Spike History Records recent spiking activity for plasticity and memory: - `spikeTimes`: Timestamps of recent spikes - `firingRate`: Average firing rate over time window - `refractoryRemaining`: Time remaining in refractory period ### Neuron Parameters #### Basic Parameters ```cpp struct NeuronParameters { // LIF parameters float membraneCapacitance; // 1.0 nF (default) float timeConstant; // 20.0 ms (default) float restingPotential; // -65.0 mV (default) float threshold; // -50.0 mV (default) float leakConductance; // 0.1 mS (default) // Refractory parameters uint32_t refractoryPeriod; // 2.0 ms (default) float adaptationStrength; // 0.0 (default) // Plasticity parameters float initialSynapticStrength; // 1.0 (default) float plasticityRate; // 0.01 (default) // Type-specific parameters NeuronType neuronType; // Internal, Sensory, Motor }; ``` #### Advanced Parameters ```cpp struct AdvancedNeuronParameters { // Dynamics parameters float voltageReset; // Reset voltage after spike float voltageDecay; // Decay rate during refractory float adaptationTimeConstant; // Transmission delay float spatialSpread; // Spatial influence radius float temporalKernel; // Temporal influence kernel }; ``` ### Neuron Operations #### Initialization ```cpp Neuron::Neuron(NeuronId id) // Creates new neuron with specified ID void Neuron::setType(NeuronType type) // Sets neuron type (Internal, Sensory, Motor) void Neuron::setMembranePotential(MembranePotential potential) // Sets initial membrane potential void Neuron::setThreshold(MembranePotential threshold) // Sets firing threshold void Neuron::setRefractoryPeriod(uint32_t steps) // Sets refractory period duration ``` #### State Update (stepLIF) ```cpp void Neuron::stepLIF(TimestepDuration dt, TimestepDuration time) // Updates neuron dynamics for one time step // Key operations: 1. Multiple inputs and outputs - Full plasticity capabilities - Complex dynamics - Internal state management #### Sensory Neurons **Purpose**: Receive external input **Characteristics**: - Specialized input receptors - Limited output capacity - Reduced plasticity - Fixed response properties #### Motor Neurons **Purpose**: Generate output actions **Characteristics**: - Specialized output pathways - Limited input integration - High reliability - Fast response times ### Neuron Connectivity #### Synapse Management ```cpp void Neuron::addIncomingSynapse(SynapseHandle synapse) // Adds incoming synaptic connection void Neuron::addOutgoingSynapse(SynapseHandle synapse) // Adds outgoing synaptic connection bool Neuron::hasConnectionTo(Neuron& other) const // Checks if connected to other neuron ``` #### Neural Population **Group of neurons with shared properties**: - **Population-based Processing**: Parallel processing of neuron groups - **Shared Resources**: Common parameters and state - **Efficient Organization**: Reduced memory overhead - **Specialized Function**: Distinct roles within brain regions #### Neural Region **Brain region containing multiple populations**: - **Regional Specialization**: Different functions per region - **Inter-region Connectivity**: Connections between regions - **Functional Integration**: Coordinated processing across regions - **Development**: Region-specific maturation patterns ### Mathematical Models #### LIF Differential Equation ``` τ_m * dV/dt = -g_L * (V - E_L) + I_syn Where: - V: Membrane potential (mV) - τ_m: Membrane time constant (ms) - g_L: Leak conductance (mS) - E_L: Resting potential (mV) - I_syn: Total synaptic current (nA) ``` #### Spike Generation Condition ``` If V ≥ V_th and not in refractory period: Generate spike at time t V ← V_reset Enter refractory period ``` #### Synaptic Integration ``` I_syn(t) = Σ w_ij * ∑ S_j(t - d_ij) Where: - w_ij: Synaptic weight from neuron j to i - S_j: Spike train of neuron j - d_ij: Transmission delay ``` #### Refractory Dynamics ``` V(t) = { V_reset, if t < t_ref V_leak + (V(t_ref) - V_leak) * exp(-(t - t_ref)/τ_m), otherwise } ``` ### Implementation Details #### Memory Layout ```cpp struct Neuron::Impl { NeuronId id; NeuronType type; NeuronState state; RegionId regionId; PopulationId populationId; // LIF parameters static constexpr float MEMBRANE_CAPACITANCE = 1.0f; // nF static constexpr float TIME_CONSTANT = 20.0f; // ms static constexpr size_t MAX_SPIKE_HISTORY = 100; // Synaptic inputs float totalCurrent; // Total synaptic current this step float synapticInput; // Accumulated synaptic input std::vector spikeHistory; std::vector incomingSynapses; std::vector outgoingSynapses; // Plasticity PlasticityFlags plasticityFlags; }; ``` #### Performance Optimizations ```cpp // Local variable caching to reduce member access float currentV = pImpl->state.membranePotential; float currentI = pImpl->totalCurrent; // Optimized branching logic with early returns if (currentV >= pImpl->state.threshold) { if (!pImpl->state.isInRefractory()) { // Generate spike } return; } ``` ### Testing and Validation #### Unit Tests - Check leak conductance and time constant values - Verify refractory period settings - Ensure synaptic weights are within bounds #### Issue 2: Excessive Spiking **Problem**: Neurons firing at unrealistic rates. **Solution**: - Adjust firing thresholds - Increase refractory periods - Check adaptation mechanisms #### Issue 3: Poor Convergence **Problem**: Learning not progressing effectively. **Solution**: - Verify STDP parameters - Check neuromodulator settings - Validate synaptic weight bounds ### API Reference #### Neuron Class Methods ```cpp // Construction and Destruction Neuron(NeuronId id) ~Neuron() Neuron(Neuron&& other) noexcept // State Management void setType(NeuronType type) void setMembranePotential(MembranePotential potential) void setThreshold(MembranePotential threshold) void setFiringState(FiringState state) void setFiringRate(FiringRate rate) // Synaptic Operations void addToMembranePotential(MembranePotential delta) void setRefractoryPeriod(uint32_t steps) // State Queries MembranePotential getMembranePotential() const MembranePotential getThreshold() const FiringState getFiringState() const FiringRate getFiringRate() const uint32_t getRefractoryPeriod() const MembranePotential getLeakConductance() const // Connectivity void addIncomingSynapse(SynapseHandle synapse) void addOutgoingSynapse(SynapseHandle synapse) std::vector getIncomingSynapses() const std::vector getOutgoingSynapses() const // Dynamics void decrementRefractory() void generateSpike(Timestamp time) void stepLIF(TimestepDuration dt, TimestepDuration time) void updatePlasticity(float dt, const PlasticityRule& rule) // State Queries bool shouldFire() const std::vector getSpikeHistory() const float getTotalSynapticCurrent() const NeuronId getId() const NeuronType getType() const RegionId getRegionId() const PopulationId getPopulationId() const ``` ### Future Directions #### Enhanced Models -
