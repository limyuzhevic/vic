# Synapse Guide ## Overview Synapses are the fundamental communication channels in NLM, transmitting signals between neurons through chemical and electrical processes. Synapses enable neural communication, plasticity, and network formation in the computational brain. ## Synapse Types ### Electrical Synapses **Properties**: - **Direct Coupling**: Gap junctions allow direct ion flow - **Bidirectional**: Signals flow in both directions - **Fast**: No synaptic delay - **All-or-Nothing**: Binary transmission **Use Cases**: - Rapid signal propagation - Synchronization of neural populations - Stability maintenance ### Chemical Synapses **Properties**: - **Unidirectional**: Signals flow one direction - **Modifiable**: Synaptic strength can change - **Delayed**: Transmission delay (1-5 ms) - **Graduated**: Variable strength based on parameters **Use Cases**: - Complex neural computation - Plasticity and learning - Network modulation - Information filtering ## - **Positive Effect**: Depolarize post-synaptic neuron - **Higher Threshold**: Require stronger pre-synaptic input - **LTP Dominance**: Tendency to strengthen with activity - **AMPA Receptors**: Glutamate-based transmission **Biological Analogy**: - **Excitatory Postsynaptic Potentials (EPSPs)** - **Glutamatergic Synapses** - **AMPA Receptor-Mediated Transmission** ### Inhibitory Synapses **Characteristics**: - **Negative Effect**: Hyperpolarize post-synaptic neuron - **Lower Threshold**: Activated by weaker pre-synaptic input - **LTD Dominance**: Tendency to weaken with activity - **GABAergic Transmission**: GABA-based transmission **Biological Analogy**: - **Inhibitory Postsynaptic Potentials (IPSPs)** - **GABAergic Synapses** - **GABA_A Receptor-Mediated Transmission** ### Modulatory Synapses **Characteristics**: - **Chemical Modulation**: Release neuromodulators - **Slow Dynamics**: Longer time constants - **Wide Influence**: Diffuse effects - **Plasticity Interaction**: Modulate other synapses **Biological Analogy**: - **Dopaminergic Synapses** - **Serotonergic Synapses** - **Peptidergic Synapses** ## Plasticity Mechanisms ### STDP (Spike-Timing-Dependent Plasticity) **Core Principle**: "Neurons that fire together, wire together; neurons that fire apart, unwire together." #### STDP Learning Rule ```cpp void Synapse::applySTDP(Neuron& preNeuron, Neuron& postNeuron, Timestamp preTime, Timestamp postTime, float learningRate) { if (postTime > preTime) { // Post after pre: Long-Term Potentiation (LTP) float delta = A_plus * exp(-(postTime - preTime) / tau_plus); strength += delta * learningRate; } else { // Post before pre: Long-Term Depression (LTD) float delta = -A_minus * exp(-(preTime - postTime) / tau_minus); strength += delta * learningRate; } constrainStrength(); recordActivation(preTime); } ``` **Parameters**: - `A_plus`: Maximum LTP amplitude - `A_minus`: Maximum LTD amplitude - `tau_plus`: LTP time constant - `tau_minus`: LTD time constant #### STDP Implementation Details ```cpp // Continuous STDP (alternative to event-based) void applyContinuousSTDP(float preRate, float postRate, float dt) { // Rate-based STDP implementation float weightChange = stdpLearningRate * (preRate * postRate - postRate * preRate); strength += weightChange * dt; } ``` ### Hebbian Learning **Core Principle**: Co-activation strengthens connections. #### Hebbian Learning Rule ```cpp void Synapse::applyHebbian(Neuron& preNeuron, Neuron& postNeuron, float learningRate) { // Calculate correlation-based learning float preActivity = preNeuron.getFiringRate(); float postActivity = postNeuron.getFiringRate(); // Hebbian rule with normalization float weightChange = learningRate * preActivity * postActivity; if (weightChange > 0) { weightChange *= (1.0f - strength); // Prevent runaway excitation } strength += weightChange; constrainStrength(); } ``` ### Homeostatic Plasticity **Core Principle**: Network stability through synaptic scaling. #### Synaptic Scaling ```cpp void Synapse::applyHomeostatic(float targetActivity, float learningRate) { // Calculate average post-synaptic activity float averageActivity = calculatePostSynapticActivity(); // Scale strength toward target float scalingFactor = targetActivity / averageActivity; if (scalingFactor > 1.0f) { // Potentiate all synapses strength *= scalingFactor; } constrainStrength(); } ``` ### Neuromodulation-Dependent Plasticity **Core Principle**: Plasticity modulated by global signals. #### Reward-Modulated STDP ```cpp void Synapse::applyRewardModulatedSTDP(Neuron& preNeuron, Neuron& postNeuron, Timestamp preTime, Timestamp postTime, float rewardPredictionError, float learningRate) { // Apply STDP with reward modulation applySTDP(preNeuron, postNeuron, preTime, postTime, learningRate); // Scale by reward prediction error float modulation = 1.0f + rewardPredictionError * neuromodulationGain; strength *= modulation; constrainStrength(); } ``` ## Synapse Connectivity ### Neural Network Formation ```cpp // Create synaptic connection void createSynapse(Neuron& preNeuron, Neuron& postNeuron, SynapseType type, float Information processing pathways - **Sensory Maps**: Organized sensory representations ## Mathematical Models ### Synaptic Transmission Equation ``` V_post(t) = V_rest + Σ w_ij * Σ S_j(t - d_ij) * R(t) Where: - V_post: Post-synaptic membrane potential - V_rest: Resting membrane potential - w_ij: Synaptic weight from neuron j to i - S_j: Spike train of neuron j - d_ij: Transmission delay - R(t): Transmission function (time-dependent) ``` ### Short-Term Plasticity Models #### Tsodyks-Markram Model ``` // Synaptic dynamics: // dU/dt = (U_0 - U) / τ_rec - U * R * f // dR/dt = (1 - R) / τ_fac - U * R * f // Where: // U: Utilization of resources // R: Fraction of available resources // f: Presynaptic firing rate // τ_fac: Facilitation time constant // τ_rec: Recovery time constant ``` ### STDP Mathematical Formulation ``` // Pair-based STDP: // Δw_{ij} = { // A_+ * exp(-(t_post - t_pre)/τ_+), if t_post > t_pre // -A_- * exp(-(t_pre - t_post)/τ_-), if t_pre > t_post // 0, otherwise // } // Rate-based STDP: // Δw_{ij} = A * (ν_post(t) - ν_pre(t)) * w_{ij} ``` ### Homeostatic Plasticity ``` // Synaptic scaling: // w_ij(t) = w_ij(0) * (ν_target / ν_avg) // Where: // ν_target: Target average activity // ν_avg: Actual average activity ``` ## Implementation Details ### Memory Layout for Efficiency ```cpp struct Synapse::Impl { SynapseId id; NeuronId preNeuronId; NeuronId ### Issue 1: Unstable Network Dynamics **Problem**: Oscillations or runaway excitation/ depression. **Solution**: - Check synaptic weight bounds - Verify homeostatic mechanisms - Adjust STDP parameters - Ensure proper initialization ### Issue 2: Delayed Signal Transmission **Problem**: Signals arriving later than expected. **Solution**: - Verify delay settings - Check transmission timing - Validate synaptic dynamics - Ensure proper spike recording ### Issue 3: Poor Learning Convergence **Problem**: Network not learning effectively. **Solution**: - Check plasticity rule parameters - Verify neuromodulator settings - Validate learning rate adjustments - Ensure proper spike timing ### Issue 4: Synaptic Saturation **Problem**: Synapses reaching extreme values. **Solution**: - Implement stronger weight constraints - Add activity-dependent limits - Verify homeostatic mechanisms - Check input range normalization ## API Reference ### Synapse Class Methods ```cpp //
