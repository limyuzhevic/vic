# Tutorial Guide ## Overview The Tutorial Guide provides step-by-step instructions for common NLM tasks and use cases. It covers tutorials for beginners, intermediate users, and advanced users, with practical examples and hands-on exercises. ## Tutorial Structure ### Tutorial Categories 1. **Beginner Tutorials**: Basic concepts and simple examples 2. **Intermediate Tutorials**: More complex tasks and advanced features 3. **Advanced Tutorials**: Complex use cases and customization 4. **Project-Based Tutorials**: Complete projects with step-by-step guidance ### Tutorial Format Each tutorial includes: - **Objective**: What the tutorial aims to accomplish - **Prerequisites**: Required knowledge and setup - **Step-by-Step Instructions**: Detailed, numbered steps - **Code Examples**: Complete, working code examples - **Expected Output**: What the user should see or experience - **Further Exploration**: Additional topics to explore ## Beginner Tutorials ### Tutorial 1: Hello NLM - Your First Simulation #### Objective Run your first NLM simulation and understand the basic components and workflow. #### Prerequisites - Number of neurons simulated - Number of synapses created - Simulation duration - Performance metrics **Expected Output** ``` NLM Phase 2 Neural Computation Demo ================================== Configuration: Timestep: 0.001 ms Max Neurons: 100 Max Synapses: 1000 Random Seed: 42 Simulation Results: Neurons Created: 100 Synapses Created: 1000 Simulation Time: 2.34 ms Performance: 42,735 neurons/sec Success!
