# NLM Documentation

Welcome to the NLM (Neural Learning Machine) documentation! This documentation is organized to support learners at all levels, from complete beginners to advanced users.

## Documentation Hierarchy

The NLM documentation follows a progressive learning path:

### Level 1: Beginner (Getting Started)
- **Quick Start Guide** - 15-minute tutorial to get up and running
- **Basic Concepts** - Understanding neurons, brains, and the NLM framework
- **Simple Examples** - Copy-paste working examples
- **Installation Guide** - Platform-specific installation instructions

### Level 2: Intermediate (Practical Usage)
- **Core API Reference** - Comprehensive Python API documentation
- **Configuration Guide** - Setting up brains and worlds
- **Simulation Basics** - Running experiments and analyzing results
- **Troubleshooting** - Common issues and solutions

### Level 3: Advanced (Expert Features)
- **Advanced Configuration** - Fine-tuning performance and behavior
- **Neuromodulation Systems** - Deep dive into dopamine, curiosity, and novelty
- **Development Stages** - Brain maturation and critical periods
- **Performance Optimization** - Benchmarking and scaling
- **Research Use Cases** - Advanced experimental setups

### Reference (System Documentation)
- **Architecture Overview** - Component relationships and data flow
- **Performance Characteristics** - Scaling and benchmarking data
- **Scientific Background** - Biological inspiration and limitations
- **Migration Guide** - From older versions to current API

## Documentation Standards

All documentation follows these guidelines:

- **Beginner-friendly**: Use analogies and step-by-step instructions
- **Practical**: Include working code examples
- **Progressive**: Build concepts from simple to complex
- **Searchable**: Clear table of contents and index
- **Maintainable**: Consistent formatting and structure
