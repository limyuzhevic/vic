# NLM Advanced User Guide

## Overview

This document provides comprehensive guidance on using the NLM (Neural Learning Machine) framework, with special focus on the advanced features and improvements made during Phase 2 (Real Neural Computation).

## Quick Start

### Basic Usage

The NLM framework provides both basic and advanced functionality for different user needs.

**Basic Usage:**
```bash
# Run basic neural computation simulation
./nlm_phase2 --neurons 500 --regions 1 --steps 1000
```

**Advanced Usage:**
```bash
# Run with advanced monitoring and profiling
./nlm_phase2 --neurons 1000 --enable-monitoring --enable-profiling \
           --enable-network-analysis --enable-synapse-analysis
```

### Configuration File

Create a configuration file (`config.txt`) with key=value pairs:
```
# NLM Configuration File
# Generated by NLM neural simulation framework

# Neuron configuration
neuron_count = 500
region_count = 1
connection_probability = 0.15

# Plasticity parameters
stdp_ltp_weight = 0.02
stdp_ltd_weight = 0.015
stdp_tau = 20.0

# Structural plasticity parameters
synaptogenesis_rate = 0.0001
pruning_rate = 0.00001

# Neuromodulation parameters
dopamine_baseline = 0.05
curiosity_sensitivity = 2.0
prediction_error_threshold = 0.01
```

## Common Issues and Solutions

### Issue: Configuration File Not Found

**Solution:** Ensure the configuration file exists and is in the correct location:

```bash
# Check if file exists
ls -la config.txt

# Create configuration file
cat > config.txt << EOF
neuron_count = 500
region_count = 1
connection_probability = 0.15
EOF
```

### Issue: Invalid Configuration Values

**Solution:** Use valid numeric values and check for syntax errors:

```bash
# Valid configuration
cat > config.txt << EOF
neuron_count = 500
region_count = 1
connection_probability = 0.15
EOF

# Invalid configuration (will cause errors)
cat > config.txt << EOF
neuron_count = abc  # Invalid: must be integer
region_count = 1.5  # Invalid: must be integer
connection_probability = 2.0  # Invalid: must be between 0 and 1
EOF
```

### Issue: Memory Usage Too High

**Solution:** Reduce neuron count or increase system memory:

```bash
# Reduce neuron count
./nlm_phase2 --neurons 200

# Or increase system swap space
 sudo swapon -s
```

### Issue: Simulation Takes Too Long

**Solution:** Reduce simulation steps or use profiling to identify bottlenecks:

```bash
# Reduce simulation steps
./nlm_phase2 --steps 500 --enable-profiling

# Use profiling to identify bottlenecks
./nlm_phase2 --enable-profiling --profile-output profile.txt
```

## Advanced Configuration Options

### Neuron Configuration

```bash
--neurons <count>              Number of neurons (default: 500)
--regions <count>              Number of regions (default: 1)
--steps <count>                Number of simulation steps (default: 1000)
```

### Plasticity Configuration

```bash
--stdp_ltp_weight <weight>      STDP LTP weight (default: 0.02)
--stdp_ltd_weight <weight>      STDP LTD weight (default: 0.015)
--stdp_tau <tau>                STDP time constant (default: 20.0)
--synaptogenesis_rate <rate>    Synaptogenesis rate (default: 0.0001)
--pruning_rate <rate>          Pruning rate (default: 0.00001)
```

### Neuromodulation Configuration

```bash
--dopamine_baseline <level>    Dopamine baseline level (default: 0.05)
--curiosity_sensitivity <sens>   Curiosity sensitivity (default: 2.0)
--prediction_error_threshold <thresh> Prediction error threshold (default: 0.01)
```

## Troubleshooting

### Common Error Messages and Solutions

1. **"File not found or cannot be opened"**
   - Solution: Ensure the configuration file exists and has proper permissions.

2. **"Invalid configuration format"**
   - Solution: Check for syntax errors in the configuration file.

3. **"Type conversion failed"**
   - Solution: Ensure configuration values match expected types (integers, floats, strings).

4. **"Unknown configuration key"**
   - Solution: Check for typos in configuration key names.
