# NLM Advanced User Guide

## Overview

This guide provides comprehensive documentation for advanced users of the Neural Learning Machine (NLM) framework. It covers advanced configuration, experiment control, performance optimization, and debugging techniques for experienced users who want to push the boundaries of neural simulation.

## Advanced Configuration

### Configuration Management

NLM provides a sophisticated configuration system that allows fine-grained control over brain parameters, learning dynamics, and simulation behavior.

#### Advanced Configuration Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `learning_rate` | float | 0.01 | Synaptic weight change rate |
| `neuron_count` | int | 1000 | Total number of neurons in the brain |
| `structure_plasticity` | bool | true | Enable structural plasticity (new connections) |
| `development_enabled` | bool | true | Enable developmental stages |
| `curiosity_enabled` | bool | true | Enable curiosity-driven exploration |
| `reward_modulation` | bool | true | Enable reward-modulated learning |
| `novelty_detection` | bool | true | Enable novelty detection |
| `prediction_system` | bool | true | Enable predictive coding |
| `working_memory_size` | int | 100 | Working memory capacity |
| `episodic_memory_capacity` | int | 1000 | Maximum episodes in episodic memory |
| `plasticity_mode` | string | "stdp" | Primary plasticity rule (stdp/hebbian/stdp-hebbian) |
| `development_stages` | int | 6 | Number of developmental stages |
| `simulation_timestep` | float | 0.001 | Simulation time step in seconds |
| `checkpoint_interval` | int | 1000 | Steps between checkpoints |
| `replay_interval` | int | 100 | Steps between memory replay events |
| `consolidation_interval` | int | 5000 | Steps between memory consolidation |

## Advanced Experiment Control

### Experimental Framework

NLM provides a sophisticated experimental framework for conducting controlled studies of neural systems.

#### Running Custom Experiments

```bash
# Run a development study
nlm-experiment development-study --plasticity-mode "stdp-hebbian" --stages "6,8,10"

# Run curiosity exploration experiment
nlm-experiment curiosity-study --novelty-threshold 0.6 --exploration-temperature 2.0

# Run memory consolidation study
nlm-experiment memory-study --consolidation-interval 1000 --replay-interval 200

# Run transfer learning experiment
nlm-experiment transfer-learning --source " maze-navigation " --target "social-learning"
```

#### Experimental Parameters

| Parameter | Description | Example Values |
|-----------|-------------|----------------|
| `plasticity_mode` | Type of plasticity rule | "stdp", "hebbian", "stdp-hebbian" |
| `development_stages` | Number of developmental stages | 4, 6, 8 |
| `novelty_threshold` | Threshold for novelty detection | 0.3, 0.5, 0.7 |
| `exploration_temperature` | Randomness in action selection | 0.5, 1.0, 2.0 |
| `consolidation_interval` | Memory consolidation frequency | 500, 1000, 2000 |
| `replay_interval` | Memory replay frequency | 50, 100, 200 |

### Perturbation Studies

```bash
# Apply perturbations to study system response
nlm-perturb "reward-noise 0.1"  # Add noise to reward signals
nlm-perturb "input-block vision"  # Block visual input
nlm-perturb "connection-prune 0.2"  # Remove 20% of synapses
nlm-perturb "neuron-damage 10"  # Damage 10 neurons
```

#### Perturbation Analysis

```python
# Study system response to perturbations
perturbation_results = nlm.perturbation_study(
    perturbations=["reward-noise", "input-block", "connection-prune"],
    steps=1000,
    analysis=True
)

# Analyze recovery dynamics
recovery = perturbation_results.get_recovery_dynamics()
print(f"Recovery time: {recovery['mean_recovery_time']} steps")
```

### Script Examples

```python
#!/usr/bin/env python3
"""
Advanced NLM Experimental Protocol
"""

import nlm
import json
import time

def curiosity_development_experiment():
    """Advanced experiment combining curiosity and development"""
    
    # Configuration
    config = {
        "learning_rate": 0.005,
        "curiosity_enabled": True,
        "development_enabled": True,
        "novelty_detection": True,
        "working_memory_size": 200,
        "episodic_memory_capacity": 2000
    }
    
    # Create brain with advanced configuration
    brain = nlm.createBrain(nlm.createAdvancedConfig(config))
    
    # Create world and agent
    world = nlm.createSimpleWorld()
    world.configure(20, 20, 8, 8)
    agent = nlm.createAgentBrain(brain)
    
    # Initialize with world
    agent.initialize(world)
    
    # Enable advanced features
    agent.enableCuriosity(True)
    agent.enableDevelopment(True)
    agent.enableRewardModulation(True)
    
    # Run experiment
    results = {
        "steps": 2000,
        "curiosity_levels": [],
        "novelty_levels": [],
        "development_stages": [],
        "performance_metrics": []
    }
    
    for step in range(2000):
        # Update world
        world.update(0.1)
        
        # Get sensory input
        percept = world.getSensoryPercept()
        
        # Process and record
        agent.processSensoryInput(percept)
        brain.step(step)
        
        # Record metrics
        results["curiosity_levels"].append(agent.getCuriosityLevel())
        results["novelty_levels"].append(agent.getNoveltyLevel())
        results["development_stages"].append(brain.getDevelopmentalStage())
        
        # Get performance metrics
        if step % 100 == 0:
            metrics = {
                "step": step,
                "firing_rate": brain.getAverageFiringRate(),
                "total_spikes": brain.getTotalSpikeCount(),
                "memory_usage": len(brain.getWorkingMemory().getMemoryNeurons()),
                "curiosity": agent.getCuriosityLevel(),
                "novelty": agent.getNoveltyLevel()
            }
            results["performance_metrics"].append(metrics)
        
        # Print progress
        if step % 500 == 0:
            print(f"Step {step}: Curiosity={agent.getCuriosityLevel():.3f}, "
                  f"Novelty={agent.getNoveltyLevel():.3f}, "
                  f"DevStage={brain.getDevelopmentalStage()}")
    
    # Save results
    with open("curiosity_development_experiment.json", "w") as f:
        json.dump(results, f, indent=2)
    
    # Generate analysis
    analysis = nlm.analyze_experiment_results(results)
    
    print("Experiment completed successfully!")
    print(f"Average curiosity level: {sum(results['curiosity_levels'])/len(results['curiosity_levels']):.3f}")
    print(f"Final development stage: {results['development_stages'][-1]}")
    
    return results

if __name__ == "__main__":
    curiosity_development_experiment()
```
