# Enhanced NLM Python API Examples

This directory contains comprehensive examples and tutorials demonstrating the enhanced NLM Python API capabilities.

## Overview

The enhanced NLM Python API provides advanced neural network simulation and analysis capabilities with features including:

- **Configuration Management**: Advanced configuration templates, validation, and optimization
- **Neural Network Simulation**: Brain models with neurons, synapses, and plasticity
- **Metrics Collection**: Performance monitoring and data analysis
- **Feature Detection**: System capabilities and compatibility checking
- **Data Export**: Multiple export formats for simulation data

## Running Examples

Most examples can be run directly with Python 3.8+:

```bash
python example_name.py
```

Some examples may require additional dependencies. Check individual example files for requirements.

## Example Structure

1. **Clear documentation** explaining the purpose and concepts

For beginners, we recommend starting with the Getting Started tutorials and progressing through the categories in order:

1. Start with `getting_started/` examples
2. Move to `intermediate/` examples
3. Explore `advanced/` examples for complex scenarios
4. Study `real_world/` examples for practical applications
5. Focus on `performance/` examples for optimization
6. Explore `learning/` examples for development concepts
7. Review `integration/` examples for framework integration
8. Use `features/` examples for specific feature demonstrations
9. Consult `reference/` examples for best practices and patterns
