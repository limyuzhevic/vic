## Usage Instructions

### Running Examples
1. **Prerequisites:** Ensure Python 3.8+ and NLM Python bindings are installed
2. **Basic Execution:** Run any `.py` file from the examples directory
3. **Complete Set:** Run all examples in the examples directory

### Example Execution Commands
```bash
# Run a specific example
cd python/examples
python getting_started/basic_setup.py

# Run all examples
for example in $(find . -name "*.py" -type f); do
    echo "Running: $example"
    python "$example"
    echo "---"
done
```
