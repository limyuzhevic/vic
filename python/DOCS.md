# NLM Python API Complete Reference

This document provides complete reference documentation for the NLM Python API,
covering all available functions, classes, and usage patterns.

## Overview

The NLM Python API provides access to the Neural Learning Machine (NLM) artificial
brain simulation system. The API includes:

- **Core API**: Basic brain creation and simulation functions
- **Advanced API**: Extended functionality for power users
- **Command Line Interface**: CLI tools for running simulations
- **Visualization Tools**: Plotting and analysis functions
- **Examples**: Comprehensive examples and demonstrations

## Core API Reference

### Module: `pynlm`

#### Functions

##### createBrain(config)
Creates a virtual brain with neurons and synapses.

**Parameters:**
- `config`: Brain configuration object (use `createDefaultConfig()` for simple setup)

**Returns:**
- `Brain`: Brain object ready for simulation

**Example:**
```python
import pynlm

brain = pynlm.createBrain(pynlm.createDefaultConfig())
brain.initialize()
```

##### createDefaultConfig()
Creates default brain configuration.

**Parameters:**
- None

**Returns:**
- `Config`: Default configuration object

**Example:**
```python
import pynlm

config = pynlm.createDefaultConfig()
brain = pynlm.createBrain(config)
```

##### createSimpleWorld()
Creates a simple world for brain-agent interaction.

**Parameters:**
- None

**Returns:**
- `World`: World object for simulation

**Example:**
```python
import pynlm

world = pynlm.createSimpleWorld()
world.configure(width=10, height=10, visionWidth=8, visionHeight=8)
world.reset()
```

##### createAgentBrain(brain)
Creates an agent brain that connects brain to world.

**Parameters:**
- `brain`: Brain object to connect

**Returns:**
- `Agent`: Agent object

**Example:**
```python
import pynlm

brain = pynlm.createBrain(pynlm.createDefaultConfig())
agent = pynlm.createAgentBrain(brain)
```

#### Classes

##### Brain
Main brain object for simulation.

**Methods:**

###### initialize()
Starts up the brain. Always call this before using the brain!

**Parameters:** None
**Returns:** None

**Example:**
```python
brain.initialize()
```

###### step(step_number)
Makes the brain process one moment in time.

**Parameters:**
- `step_number`: Step number for this processing step

**Returns:** None

**Example:**
```python
for i in range(100):
    brain.step(i)
```

###### getTotalNeuronCount()
Returns total number of neurons in the brain.

**Parameters:** None
**Returns:** Number of neurons (int)

**Example:**
```python
neuron_count = brain.getTotalNeuronCount()
```

###### getTotalSpikeCount()
Returns total number of spikes generated by the brain.

**Parameters:** None
**Returns:** Number of spikes (int)

**Example:**
```python
spike_count = brain.getTotalSpikeCount()
```

###### getFiringNeuronCount()
Returns number of neurons currently firing.

**Parameters:** None
**Returns:** Number of firing neurons (int)

**Example:**
```python
firing_count = brain.getFiringNeuronCount()
```

###### getAverageFiringRate()
Returns average firing rate of the brain.

**Parameters:** None
**Returns:** Average firing rate (float)

**Example:**
```python
firing_rate = brain.getAverageFiringRate()
```

###### getDevelopmentalStage()
Returns current developmental stage of the brain.

**Parameters:** None
**Returns:** Developmental stage (string)

**Example:**
```python
development_stage = brain.getDevelopmentalStage()
```

###### receiveSensoryInput(percept)
Gives sensory information to the brain.

**Parameters:**
- `percept`: Sensory perception data

**Returns:** None

**Example:**
```python
percept = world.getSensoryPercept()
brain.receiveSensoryInput(percept)
```

###### produceAction()
Produces motor/action output based on motor neuron activity.

**Parameters:** None
**Returns:** Action object

**Example:**
```python
action = brain.produceAction()
```

#### World
Virtual world for brain-agent interaction.

**Methods:**

###### configure(width, height, visionWidth, visionHeight)
Configures the world's dimensions and agent's vision.

**Parameters:**
- `width`: World width
- `height`: World height
- `visionWidth`: Agent's visual field width
- `visionHeight`: Agent's visual field height

**Returns:** None

**Example:**
```python
world.configure(width=10, height=10, visionWidth=8, visionHeight=8)
```

###### update(time)
Updates the virtual world by `time` seconds.

**Parameters:**
- `time`: Time step in seconds

**Returns:** None

**Example:**
```python
world.update(0.1)
```

###### reset()
Resets the world to initial state.

**Parameters:** None
**Returns:** None

**Example:**
```python
world.reset()
```

###### getSensoryPercept()
Gets sensory perception from the world.

**Parameters:** None
**Returns:** Sensory percept object

**Example:**
```python
percept = world.getSensoryPercept()
```

###### applyMotorCommand(action, time)
Applies motor command to the world.

**Parameters:**
- `action`: Action to apply
- `time`: Simulation time

**Returns:** None

**Example:**
```python
action = agent.decodeMotorCommand()
world.applyMotorCommand(action, time)
```

#### Agent
Agent that connects brain to world.

**Methods:**

###### initialize(world)
Initializes the agent with the world.

**Parameters:**
- `world`: World object to interact with

**Returns:** None

**Example:**
```python
agent.initialize(world)
```

###### processSensoryInput(percept)
Gives sensory information to the brain.

**Parameters:**
- `percept`: Sensory perception data

**Returns:** None

**Example:**
```python
agent.processSensoryInput(percept)
```

###### decodeMotorCommand()
Reads the brain's motor neurons to decide what action to take.

**Parameters:** None
**Returns:** Motor command object

**Example:**
```python
action = agent.decodeMotorCommand()
```

###### enableRewardModulation(enabled)
Enables/disables reward-based learning.

**Parameters:**
- `enabled`: True to enable, False to disable

**Returns:** None

**Example:**
```python
agent.enableRewardModulation(True)
```

###### enableStructuralPlasticity(enabled)
Enables/disables structural plasticity (growing new connections).

**Parameters:**
- `enabled`: True to enable, False to disable

**Returns:** None

**Example:**
```python
agent.enableStructuralPlasticity(True)
```

###### enableDevelopment(enabled)
Enables/disables brain development over time.

**Parameters:**
- `enabled`: True to enable, False to disable

**Returns:** None

**Example:**
```python
agent.enableDevelopment(True)
```

###### enableCuriosity(enabled)
Enables/disables curiosity-driven exploration.

**Parameters:**
- `enabled`: True to enable, False to disable

**Returns:** None

**Example:**
```python
agent.enableCuriosity(True)
```

## Command Line Interface Reference

### Module: `pynlm.cli`

#### Commands

##### simple
Run simple brain simulation.

**Arguments:**
- `--neurons`: Number of neurons (default: 500)
- `--steps`: Number of simulation steps (default: 1000)

**Example:**
```bash
nlm simple --neurons 1000 --steps 500
```

##### brain-in-world
Run brain in world simulation.

**Arguments:**
- `--width`: World width (default: 10)
- `--height`: World height (default: 10)
- `--vision-width`: Agent vision width (default: 8)
- `--vision-height`: Agent vision height (default: 8)
- `--steps`: Number of simulation steps (default: 500)
- `--reward-modulation`: Enable reward modulation
- `--structural-plasticity`: Enable structural plasticity
- `--development`: Enable development
- `--curiosity`: Enable curiosity

**Example:**
```bash
nlm brain-in-world --width 20 --height 20 --steps 1000 --reward-modulation
```

##### advanced-agent
Run advanced agent with learning.

**Arguments:**
- `--width`: World width (default: 15)
- `--height`: World height (default: 15)
- `--vision-width`: Agent vision width (default: 8)
- `--vision-height`: Agent vision height (default: 8)
- `--steps`: Number of simulation steps (default: 1000)

**Example:**
```bash
nlm advanced-agent --width 30 --height 30 --steps 2000
```

##### memory-experiment
Run memory experiment.

**Arguments:**
- `--memory-type`: Type of memory (working, episodic, combined) (default: episodic)
- `--steps`: Number of simulation steps (default: 2000)
- `--replay-interval`: Steps between memory replay (default: 100)

**Example:**
```bash
nlm memory-experiment --memory-type episodic --steps 5000 --replay-interval 200
```

##### prediction-test
Run prediction learning test.

**Arguments:**
- `--prediction-horizon`: How far ahead to predict (default: 20)
- `--learning-rate`: Learning rate for predictions (default: 0.01)
- `--steps`: Number of simulation steps (default: 1000)

**Example:**
```bash
nlm prediction-test --prediction-horizon 50 --learning-rate 0.05 --steps 2000
```

## Troubleshooting

### Common Issues

1. **Import Error**
   ```
   Error: cannot import name 'pynlm'
   ```
   **Solution:** Ensure pynlm is properly installed:
   ```bash
   pip install -e .
   ```

2. **Attribute Error**
   ```
   AttributeError: 'Brain' object has no attribute 'step'
   ```
   **Solution:** Check that the Brain object was properly initialized:
   ```python
   brain = pynlm.createBrain(pynlm.createDefaultConfig())
   brain.initialize()  # This line is required!
   ```

3. **Missing Dependencies**
   ```
   ImportError: No module named 'matplotlib'
   ```
   **Solution:** Install required packages:
   ```bash
   pip install matplotlib
   ```

### Performance Issues

1. **Slow Simulation**
   - Use smaller brain configurations
   - Disable structural plasticity for faster simulations
   - Use appropriate timestep values

2. **Memory Usage**
   - Periodically clear memory in long-running simulations
   - Use appropriate configuration to manage memory usage
