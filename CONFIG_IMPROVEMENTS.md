# Improved NLM Configuration System

## Overview

This document describes the improved configuration system for NLM (Neural Learning Machine) Phase 2: Real Neural Computation.

## Key Improvements

### 1. **JSON Configuration Support**
- **Before**: Simple key=value format only
- **After**: Support for both JSON and simple text formats
- **Benefits**: Better human-readable configuration, IDE support, validation

### 2. **Enhanced Type Safety**
- **Before**: Limited type checking
- **After**: Comprehensive type support with validation
- **Benefits**: Fewer runtime errors, better debugging

### 3. **Improved Error Handling**
- **Before**: Silent failures on config errors
- **After**: Detailed error messages and graceful fallbacks
- **Benefits**: Better user experience, easier troubleshooting

### 4. **Advanced Features**
- **Before**: Basic configuration only
- **After**: Arrays, complex data structures, metadata
- **Benefits**: More flexible configuration options

## Programmatic API

### Creating and Saving Configuration

```cpp
#include "core/Config/Config.hpp"

auto config = std::make_shared<Config>();

// Set configuration values
config->set("random_seed", 123, ConfigSource::Runtime);
config->set("neuron_count", 1000, ConfigSource::Runtime);
config->set("connection_probability", 0.2f, ConfigSource::Runtime);

// Save to JSON file
if (config->saveToFile("my_config.json")) {
    NLM_LOG_INFO("Configuration saved to JSON file");
}
```

### Loading and Getting Configuration

```cpp
// Load from JSON file
if (config->loadFromFile("my_config.json")) {
    NLM_LOG_INFO("Configuration loaded from JSON file");
}

// Get configuration values
if (auto val = config->get<int64_t>("random_seed")) {
    NLM_LOG_INFO("Random seed: " + std::to_string(*val));
}

if (auto val = config->get<float>("connection_probability")) {
    NLM_LOG_INFO("Connection probability: " + std::to_string(*val));
}
```

### Command Line Arguments

```cpp
// The Config class automatically parses command line arguments
config->loadFromArgs(argc, argv);
```

## Error Handling

### Configuration File Loading

1. **JSON Format**: Attempts to parse as JSON first, falls back to text format
2. **Text Format**: Simple key=value parsing with comment support
3. **Error Recovery**: Invalid entries are skipped with warning messages

### Type Validation

- **Automatic type conversion**: Compatible types are converted
- **Type safety**: Incompatible types are detected and reported
- **Default values**: Missing parameters use sensible defaults

## Best Practices

### For JSON Configuration Files

1. **Indentation**: Use 2-space indentation for readability
2. **Comments**: Add comments to explain complex parameters
3. **Validation**: Validate JSON syntax before runtime
4. **Versioning**: Include version information for compatibility

### For Text Configuration Files

1. **Comments**: Use `#` or `//` for comments
2. **Quoting**: Quote string values that contain special characters
3. **Consistency**: Follow the naming conventions used in the examples

### For Command Line Usage

1. **Configuration precedence**: Command line overrides files
2. **Required parameters**: Check documentation for required settings
3. **Error reporting**: Use `--help` to see all available options

## Migration Guide

### From Phase 1 to Phase 2

If you have Phase 1 configuration files, you may need to update them:

1. **File format**: Convert from simple key=value to JSON or updated text format
2. **Parameter names**: Some parameter names have changed or been added
3. **Default values**: New defaults may be more appropriate for Phase 2

## Advanced Features

### Arrays and Complex Data

The configuration system now supports arrays:

```json
{
    "custom_parameters": [1, 2, 3, 4, 5],
    "neuron_types": ["excitatory", "inhibitory", "modulatory"],
    "learning_rates": [0.01, 0.02, 0.005]
}
```

### Nested Configuration

While not fully implemented, the system can handle nested JSON structures:

```json
{
    "plasticity": {
        "stdp": {
            "ltp_weight": 0.02,
            "ltd_weight": 0.015
        },
        "hebbian": {
            "learning_rate": 0.01
        }
    }
}
```
