     - Proper value formatting (strings in quotes, arrays in brackets)

**New saveToFile Implementation:**
```cpp
void Config::saveToFile(const std::string& filepath) const {
    std::ofstream file(filepath);
    if (!file.is_open()) {
        return false;
    }
    
    file << "# NLM Configuration File\n";
    file << "# Generated by NLM at " << std::ctime(&std::time(nullptr));
    
    for (const auto& entry : pImpl->entries) {
        file << "\n# " << entry.description << "\n";
        file << entry.key << " = ";
        
        // Proper value formatting based on type
        std::visit([&file](auto&& arg) { ... }, entry.value);
        
        file << "\n";
    }
    
    return true;
}
```

## Migration Guide

### For Python Users:

**Old API → New API:**

| Old API | New API |
|---------|---------|
| `createDefaultConfig()` | `create_simple_config()` (optimized) |
| `createBrain(config)` | `create_and_run_brain(neuron_count, steps)` |
| Manual `brain.initialize()` | Automatic initialization |
| `brain.getTotalNeuronCount()` | `stats = get_brain_stats(brain)` |
| Multiple setup loops | `brain.run(steps)` convenience |

**Migration Example:**

```python
# OLD WAY (verbose, 30+ lines):
from pynlm import createDefaultConfig, createBrain

config = createDefaultConfig()
brain = createBrain(config)
brain.initialize()
for step in range(1000):
    brain.step(step)
stats = {
    'neurons': brain.getTotalNeuronCount(),
    'spikes': brain.getTotalSpikeCount(),
    'firing_neurons': brain.getFiringNeuronCount(),
    'avg_firing_rate': brain.getAverageFiringRate(),
}

# NEW WAY (simple, 3 lines):
from pynlm import create_and_run_brain, get_brain_stats

brain = create_and_run_brain(neuron_count=500, steps=1000)
stats = get_brain_stats(brain)
print(f"Neurons: {stats['total_neurons']}, Spikes: {stats['total_spikes']}")
```
