## 🚀 USAGE EXAMPLES

### **Quick Start Example**:
```python
from python import createDefaultConfig, createBrain, createSimpleWorld, create_advanced_agent
from python.visualization import (
    real_time_monitor,
    analyze_brain_statistics,
    enable_debug_logging,
    export_to_csv,
    export_to_json,
)

# Setup
config = createDefaultConfig()
brain = createBrain(config)
world = createSimpleWorld(100, 100, 20, 20)
agent = create_advanced_agent(brain, world)

# Enable debug logging
enable_debug_logging(brain, level='info', file='debug.log')

# Run simulation
for step in range(100):
    percept = world.getSensoryPercept()
    agent.processSensoryInput(percept)
    action = agent.decodeMotorCommand()
    world.applyMotorCommand(action, step)

# Analyze and export
stats = analyze_brain_statistics(brain)
export_to_csv(brain, "results.csv")
export_to_json(brain, "results.json")
```
