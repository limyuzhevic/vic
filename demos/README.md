# NLM Python API Demo Scripts

This directory contains comprehensive demo scripts showcasing the enhanced Python API for NLM (Neural Learning Machine).

## Demo Scripts

### 1. Basic Brain Operations
- `demo_basic.py` - Basic brain creation and simulation
- `demo_brain_stats.py` - Brain statistics and monitoring
- `demo_step_simulation.py` - Step-by-step simulation

### 2. Agent-World Integration
- `demo_agent_world.py` - Complete agent simulation with world interaction
- `demo_agent_learning.py` - Learning agent with reward modulation
- `demo_advanced_agent.py` - Advanced agent with all features enabled

### 3. Configuration and Setup
- `demo_configurations.py` - Different configuration types
- `demo_config_validation.py` - Configuration validation
- `demo_safe_setup.py` - Safe setup and validation

### 4. Advanced Features
- `demo_plasticity.py` - Plasticity learning experiments
- `demo_neuromodulation.py` - Neuromodulation systems
- `demo_development.py` - Developmental stages

### 5. Monitoring and Analysis
- `demo_monitoring.py` - Real-time monitoring
- `demo_benchmark.py` - Performance benchmarking
- `demo_data_collection.py` - Data collection and analysis

### 6. Error Handling and Validation
- `demo_error_handling.py` - Robust error handling
- `demo_validation.py` - Input validation
- `demo_safe_operations.py` - Safe operations with validation

## Overview

These demo scripts showcase the enhanced Python API features including:

### New Convenience Functions
- `run_agent_simulation()` - Complete agent simulation
- `create_learning_experiment()` - Learning experiments
- `get_brain_stats()` - Comprehensive statistics
- `save_brain_with_validation()` - Safe save/load
- `create_advanced_config()` - Pre-configured configurations
- `validate_config()` - Configuration validation
- `quick_test_setup()` - Quick testing setup
- `run_learning_demo()` - Learning demonstrations
- `monitor_brain_health()` - Health monitoring

### Error Handling and Validation
- `validate_brain()` - Brain state validation
- `validate_agent()` - Agent state validation
- `validate_world()` - World state validation
- `safe_run_agent()` - Safe simulation with validation
- `benchmark_brain()` - Performance benchmarking
- `create_safe_test_config()` - Safe configuration creation
- `export_brain_stats()` - Export statistics
- `compare_brains()` - Brain comparison
- `run_safety_check()` - System safety check

### Features Demonstrated

1. **Basic Operations**: Simple brain creation and simulation
2. **Agent Integration**: Complete agent-world interaction
3. **Learning**: Plasticity and learning mechanisms
4. **Development**: Developmental stages and maturation
5. **Monitoring**: Real-time statistics and monitoring

7. **Configuration**: Various configuration types and validation
8. **Performance**: Benchmarking and optimization

## Running Demos

To run a demo, use:

```bash
python demo_script.py
```

All demos include detailed comments and print statements to help you understand the flow and results.

## Requirements

- Python 3.8+
- pynlm Python module (NLM Python bindings)
- numpy (for some demos)

## Notes

- These demos are designed to work with the enhanced NLM Python API
- Many demos include error handling and validation
- Demos showcase both basic and advanced usage patterns
- Output is designed to be educational and informative
