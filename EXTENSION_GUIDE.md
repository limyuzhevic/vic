# NLM System - Extension and Improvement Guide

## Overview

This document provides guidance for extending and improving the NLM (Neural Learning Machine) system. The system is a complex neural network simulation framework with multiple phases and integrated systems.

## Current State (as of 2026)

The NLM system has completed all major phases:

- **Phase 1**: Project skeleton, core types, configuration, neural interfaces
- **Phase 2**: Real LIF neuron dynamics, event-driven spike propagation, STDP/Hebbian plasticity, structural plasticity
- **Phase 3**: World interaction loop, sensory input/motor output, reward prediction error
- **Phase 4**: Neural prediction system, working memory, episodic memory, concept formation
- **Phase 5**: Performance optimizations, memory pools, event queues, SIMD vectorization
- **Phase 6**: All systems integrated into coherent brain loop

## Extensibility Improvements

### 1. Adding New Phase Demos

To add a new phase demo:

1. Create a new demo implementation in `src/experiments/`
2. Add the demo source file to the main CMakeLists.txt
3. Link with appropriate libraries
4. Update documentation

Example structure:
```cpp
// File: src/experiments/PhaseXDemo.cpp
#include "experiments/PhaseXExperiment.hpp"
// ... implementation

int main() {
    nlm::PhaseXDemo demo;
    demo.run();
    return 0;
}
```

### 2. Adding New Configuration Options

To add new configuration options:

1. Add to `ConfigValue` variant type in `Config.hpp`
2. Update `set()` method overloads in `Config.cpp`
3. Add convenience methods if appropriate
4. Update documentation

### 3. Extending Python Bindings

The Python bindings are auto-generated by pybind11 in `python/bindings.cpp`. To add new Python API:

1. Add C++ classes to include in bindings
2. Add Python-specific methods and constructors
3. Update documentation in `HOW_TO_USE.md`
4. Rebuild Python module

## Adding New Brain Systems

The NLM architecture supports adding new integrated systems:

### Example: Adding a New Memory System

1. Create new class in appropriate directory (e.g., `src/memory/`)
2. Implement required interfaces
3. Update `Brain::Impl` structure
4. Add initialization logic in `Brain::initialize()`
5. Update `Brain::getWorkingMemory()` etc.

### Example: Adding New Neuromodulator

1. Create new neuromodulator class
2. Implement interface in `neuromodulation/`
3. Update `Brain::Impl` with new member
4. Add to brain initialization and integration
