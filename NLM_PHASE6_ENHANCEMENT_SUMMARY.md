## 🚀 **Usage Examples**

### **Basic Usage**
```bash
# Start interactive CLI
nml

# Configure and run simulation
nml config set neurons 500
nml brain initialize
nml brain step 1000
nml brain save results.nml

# Run experiments
nml experiment run memory_test
nlm monitor start
```

### **Advanced Scripting**
```bash
# Create a simulation script
script.nml:
    nlm config set neurons 1000
    nlm config set plasticity on
    nlm brain initialize
    nlm brain step 5000
    nlm brain save advanced_simulation.nml
    nlm experiment run cognitive_test
    nlm monitor stop

# Execute script
nlm --script script.nml
```

### **Configuration Management**
```bash
# Set advanced configuration
nlm config set --neurons 1000 --regions 4 --plasticity 0.8
nlm config validate
nlm config save advanced_config.nml
```
