## Implementation Features

### Reward Computation
- Computes reward from environmental observations
- Integrates with sensory input patterns
- Implements task-specific reward heuristics

### Reward Prediction Error
- Computes difference between expected and actual rewards
- Updates prediction for next time step
- Stores prediction history
- Uses prediction error for learning

### State Management
- Current reward tracking
- Accumulated reward
- Baseline reward level
- Reward decay dynamics
- History tracking

### Integration with Brain Systems
- **Memory System**: Stores reward in episodic memory
- **Attention System**: Modulates attention based on reward magnitude
- **Dopamine System**: Signals reward and prediction error to dopamine neurons

### Neuromodulation Effects
- Modulates plasticity based on reward prediction error
- Affects neural excitability through neuromodulatory signals
- Integrates with existing neuromodulation framework

## Key Design Decisions

1. **Inheritance from Neuromodulator**: Reward is now a proper neuromodulator
2. **Pimpl Pattern**: Uses pointer-to-implementation for encapsulation
3. **Integration Points**: Properly integrates with all required brain systems
4. **State Management**: Tracks reward, prediction, and error states
5. **History Tracking**: Maintains reward and prediction history
6. **Forward Declarations**: Avoids circular dependencies
7. **Logging**: Uses NLM logging for system monitoring
