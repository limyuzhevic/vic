## 🎯 Expert Usage Examples

### Basic Simulation (Beginner):
```bash
nlm_cli.sh run --config config.yaml --steps 1000
```

### Advanced Brain Management (Expert):
```bash
nlm_cli.sh brain create --type "developmental" \
  --plasticity-factor 1.5 \
  --replay-interval 50 \
  --enable-curiosity
```

### Batch Processing (Research):
```bash
nlm_cli.sh batch \
  --directory simulations/ \
  --parallel 4 \
  --output results.csv \
  --resume
```

### Performance Analysis (Expert):
```bash
nlm_cli.sh analyze \
  --input simulation_results.json \
  --type performance \
  --generate-graph \
  --export-csv
```

### Python API (Advanced):
```python
import pynlm

# Create advanced brain with custom configuration
config = pynlm.createDefaultConfig()
config.set("learning_rate", 0.01)
config.set("curiosity_enabled", True)
config.set("development_enabled", True)

brain = pynlm.createBrain(config)
brain.initialize()

# Run complex simulation
for step in range(10000):
    brain.step(step)
    if step % 100 == 0:
        print(f"Step {step}: {brain.getAverageFiringRate()} Hz")

# Save advanced state
brain.save("advanced_brain_state.nlm")
```
