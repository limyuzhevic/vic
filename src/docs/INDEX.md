# NLM Framework Documentation

## Overview

The NLM (Neural Learning Machine) is a computational brain simulation framework that implements brain-inspired neural computation with the goal of understanding how intelligence can emerge from spiking neural dynamics.

## What NLM Is

NLM is an experimental artificial developmental brain project that implements:

- Real spiking neural computation (Leaky Integrate-and-Fire neurons)
- Event-driven spike propagation with synaptic delays
- Multiple plasticity mechanisms (STDP, Hebbian, structural)
- Developmental stages that affect plasticity rates
- Memory systems (working, episodic, associative)
- Neuromodulation (dopamine, curiosity, novelty, prediction error)
- Prediction systems for temporal sequence learning
- Cognitive mechanisms (attention, planning, concept formation, self-model, social learning)

## What NLM Is Not

- A transformer or LLM
- A chatbot
- A deep learning model
- A pretrained AI system
