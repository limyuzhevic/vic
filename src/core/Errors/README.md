// Create Errors directory

// Errors.hpp - Header file for NLM error classes
// Errors.cpp - Implementation file for NLM error classes

// The Errors directory contains:
// - Errors.hpp: Base error classes for NLM exceptions
// - Errors.cpp: Implementation of error classes

// Error classes include:
// - NLMError: Base class for all NLM exceptions
// - ConfigError: Configuration-specific errors
// - ConfigValidationError: Configuration validation errors
// - MemoryError: Memory allocation errors
// - FileError: File operation errors
// - ConfigLoadError: Configuration loading errors
// - ParameterSetError: Parameter setting errors

// These error classes provide consistent error handling throughout the NLM codebase.
