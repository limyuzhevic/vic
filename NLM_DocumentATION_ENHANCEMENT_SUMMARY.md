### Running Examples

#### Build Instructions

```bash
# Create build directory
mkdir build
cd build

# Configure with CMake
cmake .. -DCMAKE_BUILD_TYPE=Release

# Build all targets
make -j4
```

#### Run Examples

```bash
# Basic brain example
./basic_brain_example

# World interaction example
./world_interaction_example

# Memory integration example
./memory_integration_example

# Neuromodulation example
./neuromodulation_example

# Development example
./development_example
```

#### Python Bindings

```python
import pynlm

# Create brain
config = pynlm.createDefaultConfig()
brain = pynlm.createBrain(config)
brain.initialize()

# Run simulation
for step in range(1000):
    brain.step(step)
```
