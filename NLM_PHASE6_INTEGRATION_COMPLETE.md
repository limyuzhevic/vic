## 💻 Usage Examples

### 1. Basic Integration Demo
```python
import pynlm

# Create and initialize brain
config = pynlm.createDefaultConfig()
brain = pynlm.createBrain(config)
brain.initialize()

# Run integrated simulation
for step in range(1000):
    brain.step(step)  # All systems integrated!
    
print(f"✅ Complete integration demo finished!")
```

### 2. Full Agent with Learning
```python
import pynlm

# Create advanced agent
brain = pynlm.createBrain(config)
brain.initialize()
agent = pynlm.createAgentBrain(brain)
agent.initialize(world)

# Enable all learning subsystems
agent.enableRewardModulation(True)      # Dopamine
agent.enableCuriosity(True)              # Exploration
agent.enableDevelopment(True)            # Maturation
agent.enableStructuralPlasticity(True)   # Synapse growth
agent.enableMetaLearning(True)           # Self-improvement
agent.enableAdaptivePlasticity(True)     # Dynamic adjustment

# Run sophisticated learning episode
for step in range(5000):
    # Integrated processing with all systems
    world.update(0.1)
    agent.processSensoryInput(world.getSensoryPercept())
    brain.step(step)
    action = agent.decodeMotorCommand()
    world.applyMotorCommand(action, world.getSimulationTime())
```

### 3. Persistence and Resume
```python
# Create, train, and save brain
brain1 = pynlm.createBrain(config)
brain1.initialize()
for step in range(1000):
    brain1.step(step)

brain1.save("trained_brain.nlm")

# Load and continue learning
brain2 = pynlm.createBrain(config)
brain2.initialize()
brain2.load("trained_brain.nlm")
for step in range(1000):
    brain2.step(step)
```
