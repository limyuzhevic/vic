## 🚀 **USAGE EXAMPLES**

### **Basic Commands:**
```bash
# Interactive REPL
nlm_tool

# Help documentation
nlm_tool help

# Run demonstration
nlm_tool demo

# Run connectivity test
nlm_tool test connectivity

# Run plasticity test
nlm_tool test plasticity

# Run all tests
nlm_tool test all

# Start simulation for 1000 steps
nlm_tool start 1000

# Save brain state
nlm_tool save brain_state.bin

# Load brain state
nlm_tool load brain_state.bin

# Show brain status
nlm_tool status

# Show memory system status
nlm_tool memory

# Show cognition system status
nlm_tool cognition

# Show neuromodulation system status
nlm_tool neuromodulation

# Show prediction system status
nlm_tool prediction

# Show development system status
nlm_tool development

# Configure settings
nlm_tool config neuron_count=1000
nlm_tool config connection_probability=0.1
```
