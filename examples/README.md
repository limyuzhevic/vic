# Examples Directory for NLM Visualization

This directory contains example files and usage demonstrations for the NLM visualization system.

## Overview

The examples directory provides practical examples of how to use the NLM visualization and analysis tools.
These examples demonstrate various visualization scenarios and analysis techniques.

## Usage

1. Clone this repository
2. Navigate to the examples directory
3. Run the example scripts to see the visualization system in action
4. Modify the examples to suit your specific use case

## Neural Network Example

The neural_network_example.json file contains example data for neural network visualization, including:

- Neuron data (positions, activity levels, membrane potentials)
- Synapse data (weights, delays, types)
- Network topology information
