# NLM Enhanced Python Bindings - Examples Directory

This directory contains comprehensive examples demonstrating the enhanced NLM Python bindings and their modern Python features.

## Overview

The enhanced NLM Python bindings provide a modern, Pythonic interface to the NLM (Neural Learning Machine) C++ neural simulation framework. This directory contains examples that showcase:

- Basic usage patterns
- Advanced neural models
- Configuration management
- Performance optimization
- Visualization and analysis
- Real-world applications
