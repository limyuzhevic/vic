# NLM Python Example Scripts

This directory contains example scripts for using the NLM Python API.

## Example Files

### example_1_simple_brain.py
A simple example showing how to create and run a basic brain simulation.

### example_2_agent_world.py  
An example showing how to create an agent that interacts with a world.

### example_3_learning_simulation.py
An example demonstrating learning with reward modulation and curiosity.

### example_4_advanced_usage.py
Advanced examples showing how to use all the enhanced features.

### example_5_performance_monitoring.py
Examples of how to monitor and analyze simulation performance.

## Running Examples

You can run any of these examples with:

```bash
python example_1_simple_brain.py
```

Or run all examples with:

```bash
python -m examples
```

## About This Directory

This directory contains practical examples that demonstrate:

- Basic NLM functionality
- Agent-world interaction patterns  
- Learning and development
- Advanced API usage
- Performance monitoring techniques

Each example includes detailed comments and follows best practices for NLM usage.
