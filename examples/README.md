# NLM Examples - Tutorial Progression

This directory contains progressive examples for using the NLM (Neural Learning Machine) framework, from beginner to advanced usage.

## Organization

The examples are organized by difficulty and use case:

### Beginner Examples (20-40 lines)
- `simple_neural.py` - Hello World for NLM
- `brain_step.py` - Basic brain operations
- `world_interaction.py` - Simple world interaction

### Intermediate Examples (50-100 lines)
- `agent_control.py` - Complete agent with brain and world
- `learning_simulation.py` - Running learning simulations
- `sensory_processing.py` - Sensory input processing

### Advanced Examples (100+ lines)
- `plasticity_learning.py` - Complex plasticity mechanisms
- `development_simulation.py` - Brain development
- `social_learning.py` - Multi-agent learning
- `advanced_config.py` - Advanced configuration

## Running Examples

All examples can be run directly:

```bash
python examples/simple_neural.py
python examples/agent_control.py
```

## Example Structure

Each example includes:
1. Clear comments explaining each step
2. Expected output
3. Time complexity analysis
4. Tips for customization

## Getting Started

1. Start with `simple_neural.py`
2. Progress through beginner examples
3. Move to intermediate examples
4. Finally tackle advanced examples
