# pynlm Development Requirements

This file contains the dependencies needed to develop and test the pynlm package.

## Core Dependencies

These are required for basic functionality:

- **pybind11>=2.11.0**: C++ extension bindings
- **numpy>=1.20**: Numerical operations and array handling

## Development Dependencies

These are needed for development and testing:

### Testing
- **pytest>=7.0**: Test framework
- **pytest-cov>=3.0**: Coverage reporting
- **coverage>=6.0**: Code coverage measurement

### Code Quality
- **black>=22.0**: Code formatting
- **flake8>=4.0**: Linting
- **mypy>=0.950**: Type checking

### Documentation
- **sphinx>=4.0**: Documentation generator
- **sphinx-rtd-theme>=1.0**: ReadTheDocs theme
- **sphinx-autodoc-typehints>=1.11**: Type hints in documentation
- **myst-parser>=0.17**: Markdown support for documentation

### Examples and Demos
- **matplotlib>=3.5**: Plotting and visualization
- **jupyter>=1.0**: Interactive notebooks

## Development Workflow

1. **Install dependencies**: `pip install -r requirements.txt`
2. **Format code**: `black python/`
3. **Run tests**: `pytest tests/`
4. **Type checking**: `mypy python/`
5. **Build documentation**: `sphinx -b html docs/ docs/_build/html/`

## Troubleshooting

### Installation Issues

If you encounter issues during installation:

1. **Ensure you have the latest pip and setuptools**:
   ```bash
   pip install --upgrade pip setuptools wheel
   ```

2. **Check system dependencies**:
   - Compiler toolchain (gcc, clang, or MSVC)
   - Python development headers
   - BLAS/LAPACK libraries (if using numpy)

3. **Install with verbose output**:
   ```bash
   pip install -v .
   ```

### Build Issues

If the C++ extensions fail to build:

1. **Check for system dependencies**:
   ```bash
   sudo apt-get update
   sudo apt-get install build-essential cmake libpython3-dev
   ```

2. **Ensure CMake is available**:
   ```bash
   cmake --version
   ```

3. **Build with specific compiler**:
   ```bash
   export CXX=g++
   python setup.py build_ext --inplace
   ```

### Runtime Issues

If you encounter runtime errors:

1. **Check Python version**:
   ```bash
   python --version
   # Ensure it's Python 3.8 or higher
   ```

2. **Verify numpy installation**:
   ```bash
   python -c "import numpy; print(numpy.__version__)"
   ```

3. **Check memory usage**:
   ```bash
   free -h
   ```
   Ensure you have sufficient memory for neural simulations.

### Troubleshooting Common Issues

#### "ModuleNotFoundError: No module named 'pynlm'"

Ensure the package is installed:
```bash
pip install -e .
```

#### "ImportError: libstdc++.so.6: cannot open shared object file"

Ensure system dependencies are installed:
```bash
sudo apt-get install libstdc++6
```

#### "numpy.core._multiarray_umath failed to import"

Ensure numpy is properly installed:
```bash
pip install --upgrade numpy
```
