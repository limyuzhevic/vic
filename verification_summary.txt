## CLI Usage Examples

### Help and Documentation
  nlm --help                    Display comprehensive help
  nlm --help --category basic     Show only basic commands
  nlm --interactive              Enter interactive help mode
  nlm --help --category configuration  Show configuration commands

### Demo Mode Operations
  nlm --demo-mode                Run comprehensive integration demo
  nlm --phase2                   Run original Phase 2 tests
  nlm --phase6 --save brain.bin   Run Phase 6 and save brain state
  nlm --phase6 --neuron-count 2000 --region-count 2 Run with custom size

### Configuration and File Operations
  nlm --phase6 --config my_config.cfg    Load custom configuration
  nlm --phase6 --save my_brain.bin      Save brain state
  nlm --phase6 --load saved_brain.bin   Load brain state
  nlm --phase6 --iterations 5000        Run with custom iteration count

### Error Recovery and Validation
  nlm --invalid-flag            Get helpful error message with recovery suggestions
  nlm --demo-mode --phase6        Get validation error for conflicting options
  nlm --config missing.cfg       Get warning about configuration file loading

## Interactive Help System Features

  - Command search: Type 'search <term>' to find related commands
  - Category browsing: Type 'category <name>' to see category commands
  - Contextual help: Type 'help <command>' for detailed command information
  - Command listing: Type 'list' to see all available commands
  - Exit interactive mode: Type 'exit' or Ctrl+C

## Progress Indicator Features

  - Colorful progress bars for simulation steps
  - Real-time progress updates
  - Configurable progress display (enabled/disabled)
  - Shows completion percentage and estimated progress
  - Works with --quiet flag to suppress progress display
